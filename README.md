# Tetris with javascript and canvas

This is my attempt to build the classic game tetris. You can play it at [https://ptrpiero.github.io/tetris/](https://ptrpiero.github.io/tetris/)

Controls:

- ← / →: move
- ↑: rotate
- ↓: soft drop
- Space: hard drop
- P or Esc: pause / resume
- Enter: start / play again

On touch screens: tap the board to rotate, drag sideways to move, drag down to soft drop, flick down to hard drop, or use the buttons below the board.
